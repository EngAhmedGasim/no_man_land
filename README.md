# شركة القاسمي وشركاؤه للمحاماة | Al-Qasimi &amp; Partners Law Firm — الموقع الإلكتروني

## هيكل الملفات
- الصفحات العربية في الجذر: index.html, about.html, services.html, team.html, articles.html, contact.html, privacy.html
- الصفحات الإنجليزية في مجلد en/ (بنفس الأسماء)
- css/style.css — التنسيقات المشتركة لكل الصفحات (ثيم فاتح ذهبي/كريمي + وضع ليلي كامل)
- js/main.js — القائمة المتنقلة، سلايدر الآراء (قابل للسحب باللمس/الفأرة)، العدادات، نافذة قراءة المقالات، تبديل الوضع الليلي
- video/hero.mp4 و video/hero-poster.jpg — فيديو وغلاف هيرو الصفحة الرئيسية
- build.py — سكربت بايثون يولّد كل ملفات HTML من محتوى مركزي؛ لتعديل أي نص (خدمة، مقال، عضو فريق...) عدّل القيم داخل هذا الملف ثم نفّذ: python3 build.py

## صور الفريق والخدمات والعملاء
جميع الصور الحالية (صور المحامين، صور آراء العملاء، صور الخدمات، صورة قسم "من نحن") هي صور
احترافية عامة (stock) من Pexels مستخدمة كمؤقت (placeholder) بسبب عدم توفر صور حقيقية بعد.
عند توفر صور المكتب/الفريق الفعلية، استبدل معرّفات الصور في build.py:
- ثابت `ABOUT_PHOTO_ID` لصورة قسم "من نحن"
- حقل `photo` داخل قائمة `TEAM` لكل محامٍ
- حقل `photo` داخل قائمة `TESTIMONIALS` لكل عميل
- حقل `img` داخل قائمة `SERVICES` لكل خدمة
كل هذه الحقول أرقام معرّفات صور Pexels تُمرَّر إلى دالة `pexels()` — يمكن استبدالها بروابط
صوركم الخاصة مباشرة (أو برفع الصور محليًا لمجلد images/ وتعديل الدالة).

## الوضع الليلي
زر تبديل الوضع الليلي (شمس/قمر) موجود في الهيدر بكل الصفحات، ويُحفظ اختيار الزائر في
localStorage بحيث يبقى نفس الوضع عند عودته للموقع، دون أي وميض عند تحميل الصفحة.

## هيدر الصفحة الرئيسية
هيدر الصفحة الرئيسية شفاف بالكامل فوق فيديو الهيرو (نص أبيض/ذهبي)، ويتحول تلقائيًا للون
الفاتح الصلب الأصلي بمجرد أن يقوم الزائر بالتمرير لأسفل. هذا محصور بالصفحة الرئيسية فقط
عبر كلاس `page-home` على وسم body.

## قبل النشر (Before going live)
1. استبدل الصور المؤقتة (راجع الفقرة أعلاه) بصور المكتب والفريق الفعلية.
2. يمكنك استبدال video/hero.mp4 و video/hero-poster.jpg بفيديو الشركة الفعلي لاحقًا إن رغبت.
3. روابط التواصل الاجتماعي في التذييل (footer) بها "#" مؤقتًا — استبدلها بروابط حساباتكم الفعلية.
4. راجع نص سياسة الخصوصية (privacy.html) وعدّله بما يتوافق مع استشارة قانونية رسمية إذا رغبتم
   بتفاصيل أدق خاصة بكل دولة من الدول الثلاث.
5. ارفع كل الملفات كما هي (بنفس البنية، بما فيها مجلد video/) إلى أي استضافة ساكنة
   (Netlify, Vercel, GitHub Pages, أو استضافة عادية عبر FTP).

Everything works with plain static hosting — no backend/server required. Just upload the whole folder
(including the video/ directory).
